Область номера и цветовые точки

Переключитесь на окно «Мой ПВЗ», нажмите кнопку — через несколько секунд будет сделан снимок окна. Сначала выделите мышкой прямоугольник вокруг номера ячейки (можно перевыделить — старая рамка исчезнет). Затем, если нужно, кликните пипеткой по точке экрана, цвет которой должен присутствовать для разрешения печати.

Цветовые точки-триггеры

Печать выполнится только если цвет во ВСЕХ (логика «И») или ХОТЯ БЫ ОДНОЙ (логика «ИЛИ») точке совпадёт (с допуском) сразу после скана. Если нет — печать тихо отменяется, без сигнала ошибки.

Принтер

Выберите готовый размер из списка — поля ширины/высоты заполнятся сами. Если нужного размера нет, выберите «Другой размер» и введите значения вручную ниже. Ширина печати XP-370B: 20–82 мм.

Положительное значение сдвигает печать вправо/вниз, отрицательное — влево/вверх. На некоторых принтерах (в зависимости от того, как физически заправлен рулон) эти два поля могут поменяться местами по эффекту — если «влево/вправо» на деле двигает вверх-вниз, используйте вместо него поле «вверх/вниз», и наоборот.

Конвертация картинки в чёрно-белое

Термопринтер физически умеет печатать только «точка есть / точки нет», без полутонов — эти настройки определяют, как цветная/полутоновая картинка (загруженная в редакторе этикетки) превращается в 1-битное изображение.

Действует только в режиме печати «Со скриншота» (переключается на вкладке «Статус»). У номера на сайте обычно тонкий шрифт — после перевода в чёрно-белое для термопечати он может побледнеть/рассыпаться, утолщение это компенсирует.

Точность OCR

Если номер распознаётся неправильно — сначала попробуйте кнопку «Проверить область» ниже (показывает % уверенности). Тонкую настройку ниже трогайте, только если стандартных результатов недостаточно.

Расширенные настройки распознавания (порог, ансамбль, эталоны)

Если номера ячеек в вашем ПВЗ всегда лежат в известном диапазоне (например, 1-120) — укажите его: любой результат OCR вне диапазона будет автоматически отброшен ещё до печати, даже если по формату (кол-во цифр) он выглядел правдоподобно.

Ансамбль распознавания

Несколько независимых способов прочитать номер голосуют между собой — побеждает самый частый результат. Все три можно включать/выключать по отдельности.

Накопленные эталоны цифр

Цифра засчитывается "созревшей" (участвует в голосовании), когда для неё накоплено достаточно образцов (порог настраивается ниже). Число под цифрой — сколько образцов сейчас накоплено.

Экспортировать в файл

Инструкция по первому запуску

  1. Принтер. На вкладке «Принтер» выберите XP-370B из списка, укажите размер этикетки (по умолчанию 40×30 мм) и нажмите «Тестовая печать», чтобы убедиться, что печать вообще работает.
  2. Область номера. На вкладке «Область распознавания» откройте окно «Мой ПВЗ», нажмите «Откалибровать», после снимка выделите прямоугольник вокруг того места, где появляется номер ячейки, нажмите «Сохранить область номера».
  3. Точки цвета (необязательно). Если печать должна происходить только при появлении определённого индикатора (например, зелёной подсветки) — переключитесь на режим «Пипетка цвета» на том же снимке и кликните по нужной точке. Можно добавить несколько точек и выбрать логику И/ИЛИ.
  4. Проверка. Нажмите «Проверить область» — убедитесь, что номер распознаётся верно и уверенность (%) достаточно высокая. Если нет — подберите параметры OCR (увеличение, порог, инверсия) там же.
  5. Макет этикетки. На вкладке «Редактор этикетки» перетащите и измените размер рамок номера, полосы, текста и картинки. Номер и текст сами центруются и подбирают размер шрифта под рамку.
  6. Тестовый скан. На вкладке «Статус» нажмите «Запустить тестовый скан» — это прогонит весь цикл без физического сканирования.
  7. Готово. Закройте окно настроек (оно свернётся в трей, программа продолжит работать). Сканируйте товар как обычно — этикетка распечатается автоматически.

Если номер распознаётся неправильно

Откройте «Область распознавания» → «Проверить область» и посмотрите на обработанную (чёрно-белую) картинку и % уверенности. Попробуйте увеличить «Увеличение перед OCR», переключить порог бинаризации на «Ручной» и подобрать значение, либо принудительно включить/выключить инверсию — в зависимости от того, тёмный или светлый фон у номера в «Мой ПВЗ».
