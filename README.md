## О проекте

Фоновая Windows-программа: слушает сканер штрихкодов, делает снимок области
экрана приложения «Мой ПВЗ» с номером ячейки, распознаёт номер и сразу
печатает этикетку на термопринтере — без единого лишнего нажатия оператора.
Есть портативная сборка в один `.exe`, без установки Python отдельно.

> [!WARNING]
> **Основной, полностью рабочий механизм — это захват изображения с экрана**
> (детектор сканера + скриншот области + отправка на печать). А вот
> **распознавание номера через OCR пока работает нестабильно** и требует
> подбора параметров под конкретный шрифт/разрешение на вашем ПК. Не
> используйте программу в боевом режиме без предварительного тестирования —
> внимательно проверяйте, что напечатанный номер совпадает с тем, что
> реально на экране.

## Как это работает

1. **Детектор сканера** — глобальный хук клавиатуры отличает быстрый ввод
   сканера от обычного набора на клавиатуре по интервалам между символами.
2. **Захват экрана** — по срабатыванию сканера делается снимок заранее
   откалиброванной области окна «Мой ПВЗ» с номером ячейки. *(Это ядро
   программы — работает надёжно.)*
3. **Распознавание номера (OCR)** — снимок прогоняется через `pytesseract` +
   несколько дополнительных методов (сегментация по символам, сравнение с
   накопленными эталонами, OpenCV). *(Самая слабая часть на сегодня — точность
   зависит от шрифта, разрешения и освещённости монитора; настраивается
   через UI, кнопка «Проверить область».)*
4. **Печать** — при успешном распознавании номер сразу уходит на
   термопринтер по протоколу TSPL (проверено на Xprinter XP-370B, USB).

Все настройки, калибровка области экрана и визуальный редактор макета
этикетки — в локальном веб-интерфейсе (иконка в системном трее, без выхода
в интернет).

## Возможности

- Автоматическое определение скана штрихкодом (без нажатий оператора)
- Калибровка области распознавания мышкой прямо по скриншоту
- Визуальный drag-and-drop редактор макета этикетки (номер, полоса, текст, лого)
- Цветовые точки-триггеры — доп. проверка перед печатью
- Журнал печати с фильтрами и экспортом в CSV
- Портативная сборка в один `.exe` (Python, Tesseract, WebView2 — всё внутри)

## Установка и запуск (для разработки)

```bash
# 1. Python 3.11+ и Tesseract OCR должны быть установлены
#    https://github.com/UB-Mannheim/tesseract/wiki

# 2. Зависимости
pip install -r requirements.txt

# 3. Разово для pywin32
python Scripts\pywin32_postinstall.py -install

# 4. Запуск
python main.py
```

После запуска появится иконка в трее → правый клик → «Открыть настройки».
Дальше: вкладка **«Принтер»** (выбор модели, тестовая печать) →
**«Область распознавания»** (калибровка) → **«Детектор сканера»** (тайминги)
→ **«Редактор этикетки»» (макет)** → проверка полным циклом реальным
сканированием.

## Портативная сборка `.exe`

Проще всего — двойной клик по `build.bat` на Windows: он сам поднимет
виртуальное окружение, подтянет портативный Tesseract и установщик WebView2,
соберёт всё через PyInstaller. На выходе — один файл
`dist/WB_PVZ_Printer.exe`, который переносится на любой Windows ПК без
установки Python/Tesseract отдельно.

Ручная сборка:

```bash
pip install -r requirements.txt
pip install pyinstaller==6.10.0
pyinstaller build.spec --clean --noconfirm
```

## Структура проекта

```
main.py              — точка входа
engine.py             — пайплайн: скан → задержка → захват → OCR → печать
scanner_listener.py   — детектор сканера по таймингам клавиш
screen_capture.py     — поиск окна «Мой ПВЗ» и захват области экрана
ocr.py                — распознавание номера ячейки
printer_tspl.py       — сборка TSPL-команд и печать через win32print
web_ui/                — Flask backend + фронтенд локального веб-интерфейса
build.spec             — сборка в exe через PyInstaller
```

Конфигурация и логи — в `%APPDATA%\WB_PVZ_Printer\`.
