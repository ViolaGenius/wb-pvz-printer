## Что это

Утилита для сотрудников пункта выдачи Wildberries: слушает сканер
штрихкодов, делает снимок области экрана с номером ячейки в приложении
«Мой ПВЗ», распознаёт номер через OCR/ансамбль методов и сразу печатает
этикетку на термопринтере (протестировано на XP-370B, протокол TSPL).
Настройка — через локальный веб-интерфейс (иконка в трее). Есть портативная
сборка в один exe-файл для Windows, без установки Python отдельно.

## Важно: код написан и проверен вне Windows

Этот проект собран и протестирован в Linux-песочнице без реального принтера,
без окна «Мой ПВЗ» и без физического сканера. Проверено:
- синтаксис и импортируемость всех модулей;
- логика сборки TSPL-команд (`printer_tspl.py`) — сверена с официальной
  документацией TSPL/TSPL2 (TSC/Xprinter используют общий диалект);
- работа Flask API целиком (все `/api/...` эндпоинты, отдача статики фронтенда);
- загрузка/сохранение/экспорт/импорт конфигурации.

**Не проверено** (нужно тестировать на реальной машине с реальным железом):
детектор сканера через `keyboard`, захват окна через `win32gui`/`mss`, печать
через `win32print` на живом XP-370B, работа связки `pystray` + `pywebview` в
одном процессе, точность `pytesseract` на реальном шрифте «Мой ПВЗ».
Это ожидаемо — эти компоненты физически не могут быть протестированы без

## Риски и альтернативы (как и просили — до начала кодирования)

### 1. Детектор сканера (тайминги клавиш)
Реализовано по рекомендованному в ТЗ стеку: глобальный хук `keyboard`,
эвристика по интервалам между символами + `Enter`. Это самый простой и
рекомендованный ТЗ вариант.

**Альтернатива**: Raw Input API (`WM_INPUT`) с фильтрацией по device handle —
физически отделяет ввод сканера от ввода обычной клавиатуры, полностью
исключая теоретическую возможность ложного срабатывания на быстрый ручной
ввод. Минусы — сложнее реализация (Win32 message loop через ctypes/pywin32),
сложнее отлаживать. Не реализовано в этой версии (выбран вариант по
умолчанию из ТЗ); при необходимости можно добавить отдельным модулем,
не трогая остальную архитектуру — интерфейс `ScannerListener` уже
абстрагирован под замену реализации.

### 2. Точность OCR
Реализовано: `pytesseract` + upscale в 4 раза + бинаризация + whitelist
цифр + `--psm 7`. Должно неплохо работать на чётком системном шрифте, но
общей гарантии 100%-й точности OCR дать невозможно.

**Альтернатива**: распознавание по шаблонам цифр (template matching) —
поскольку шрифт в «Мой ПВЗ» фиксированный, можно один раз «обучить» программу
эталонным изображениям цифр 0–9 (снять их при калибровке) и затем сравнивать
сегменты изображения с эталонами вместо общего OCR. Даёт почти 100% точность
для фиксированного шрифта, но не реализовано в этой версии — если на практике
`pytesseract` будет ошибаться чаще, чем приемлемо, это первое, что стоит
сделать (потребует переписать только `ocr.py`, остальной пайплайн не
меняется).

### 3. Полярность бит в TSPL BITMAP
Bit=1 в реализации означает «печатать чёрную точку». Если на реальном
принтере картинка выйдет в негативе — включите
`printer.bitmap_invert` в настройках (вкладка «Принтер»), код менять не надо.

## Установка и первый запуск (для разработки/тестирования)

1. Установите Python 3.11+ (Windows).
2. Установите Tesseract OCR для Windows:
   https://github.com/UB-Mannheim/tesseract/wiki — после установки либо
   добавьте путь к `tesseract.exe` в PATH, либо укажите его явно в начале
   `ocr.py` через `pytesseract.pytesseract.tesseract_cmd = r"C:\...\tesseract.exe"`.
3. В папке проекта:
   ```
   pip install -r requirements.txt
   ```
4. Для pywin32 иногда нужно однократно выполнить пост-установочный скрипт:
   ```
   python Scripts\pywin32_postinstall.py -install
   ```
5. Запуск:
   ```
   python main.py
   ```
   Появится иконка в системном трее (фиолетовый круг WB). Клик правой
   кнопкой → «Открыть настройки».

## Первичная настройка через UI

1. Вкладка **«Принтер»** — выберите XP-370B из списка, укажите размер
   этикетки/DPI, нажмите «Тестовая печать» с произвольным номером — убедитесь,
   что печать физически работает (это шаг 2 из раздела 7 ТЗ).
2. Вкладка **«Область распознавания»** — укажите точный заголовок окна «Мой
   ПВЗ» (если отличается от значения по умолчанию), нажмите «Откалибровать»,
   переключитесь на окно «Мой ПВЗ», дождитесь снимка, выделите мышкой
   прямоугольник вокруг номера ячейки, сохраните. Проверьте кнопкой
   «Захватить и распознать сейчас».
3. Вкладка **«Детектор сканера»** — подстройте тайминги под конкретную модель
   сканера, если стандартные 40 мс не подходят (некоторые дешёвые сканеры
   эмулируют клавиатуру медленнее).
4. Вкладка **«Редактор этикетки»** — перетаскиванием разместите номер ячейки,
   полосу, статичный текст (например, название ПВЗ) и картинку/логотип.
5. Проверьте полный цикл реальным сканированием товара.

## Сборка в портативный exe (единый файл, Python + Tesseract + WebView2 внутри)

**Самый простой способ** — дважды кликнуть `build.bat` (запускать на
Windows). Скрипт сам:
1. проверит Python и создаст изолированное `build_venv`;
2. установит зависимости из `requirements.txt` и `pyinstaller`;
3. если Tesseract ещё не подготовлен — попробует поставить его через
   `winget` (пакет `UB-Mannheim.TesseractOCR`) или найдёт уже установленный
   и скопирует нужные файлы (exe + dll + `tessdata/eng.traineddata`,
   `osd.traineddata`) в `assets/tesseract/`;
4. если установщик WebView2 ещё не подготовлен — скачает официальный
   Evergreen Bootstrapper (~2 МБ) в `assets/webview2/`;
5. запустит `pyinstaller build.spec --clean --noconfirm`.

На выходе — **один файл** `dist/WB_PVZ_Printer.exe` (~120-180 МБ, зависит от
версии Tesseract), который можно скопировать на любой Windows ПК и просто
запустить: Python, все библиотеки, Tesseract и установщик WebView2 уже
внутри, ничего отдельно ставить не нужно.

- `ocr.py` при старте сам находит встроенный Tesseract
  (`assets/tesseract/tesseract.exe`, распаковывается PyInstaller во временную
  `sys._MEIPASS` при каждом запуске) — если его там нет, тихо откатывается на
  системный Tesseract из `PATH`, как раньше.
- `main.py` при старте (до создания окна) вызывает
  `webview2_setup.ensure_installed()` — если на ПК ещё нет Microsoft Edge
  WebView2 Runtime, он тихо ставится из встроенного установщика (нужен
  интернет на этом ПК один раз). Если WebView2 всё же недоступен (нет
  интернета, установщик отсутствует в сборке) — программа не падает, просто
  окно настроек откроется на старом движке (без современной вёрстки), а
  `health_check.py` покажет предупреждение на дашборде.

Если Tesseract или установщик WebView2 не удалось подготовить автоматически
(например, нет `winget` или нет интернета на машине, где собираете exe),
скрипт объяснит, что сделать вручную, и что можно продолжить без них — не
критично для самой сборки.

**Вручную, шаг за шагом** (если нужен контроль над процессом или сборка не с
Windows-машины с `build.bat`):
```
pip install -r requirements.txt
pip install pyinstaller==6.10.0
REM подготовьте assets/tesseract/tesseract.exe заранее (скопируйте туда
REM папку установленного Tesseract-OCR) — иначе распознавание не заработает
REM опционально: положите assets/webview2/MicrosoftEdgeWebview2Setup.exe
REM (Evergreen Bootstrapper с https://developer.microsoft.com/microsoft-edge/webview2/)
pyinstaller build.spec --clean --noconfirm
```
`web_ui/static` и вся папка `assets` (включая `assets/tesseract` и
`assets/webview2`, если подготовлены) включены в сборку через `datas` в
`build.spec`.

## Структура проекта

```
main.py              — точка входа, связывает всё воедино
config.py             — настройки: дефолты, загрузка/сохранение, экспорт/импорт
engine.py              — центральный пайплайн: скан → задержка → захват → OCR → печать
scanner_listener.py    — детектор сканера по таймингам клавиш
screen_capture.py      — поиск окна «Мой ПВЗ» и захват области экрана
ocr.py                 — распознавание номера ячейки
printer_tspl.py        — сборка TSPL-команд и сырая печать через win32print
sound.py               — звуковые сигналы (winsound)
tray.py                — иконка в системном трее
autostart.py           — автозапуск через реестр HKCU\...\Run
print_log.py           — журнал печати для UI
logger_setup.py        — логирование ошибок в файл
web_ui/server.py        — Flask backend локального веб-UI
web_ui/static/          — фронтенд (HTML/CSS/JS, без сборки и внешних CDN)
build.spec              — сборка в exe через PyInstaller
```

Конфигурация и логи хранятся в `%APPDATA%\WB_PVZ_Printer\`
(`config.json`, `print_log.json`, `logs\app.log`, `images\`).

## Известные допущения (см. также комментарии в коде)

- Заголовок окна ищется по вхождению подстроки, а не по точному совпадению
  (переключается галочкой «Точное совпадение заголовка»).
- Звук по умолчанию — системный `winsound.Beep` (нельзя приглушить
  программно); для более мягкого звука положите свои `.wav` в
  `assets/sounds/{capture,success,error}.wav`.
- При ошибке «окно не найдено» звуковой сигнал ошибки НЕ проигрывается
  (по ТЗ п.3.3 это привязано именно к неудаче OCR после всех попыток) —
  статус в трее при этом всё равно становится красным.
- Drag-and-drop редактор реализован на чистом JS (без Fabric.js/interact.js),
  чтобы приложение оставалось полностью автономным и не требовало интернета
  при запуске в ПВЗ.
